# Layer-effect render calibration vs Photoshop

Calibration record for rendering layer effects (Blend If, Satin, Stroke, shadows and glows, interior effects, bevel details beyond the write rules). Read this before touching src/render/layer_compositor.hpp effect passes or layer_style_mask_ops.cpp. Descriptor/write rules stay in [ps-compat.md](ps-compat.md).
Conventions: "PS" = Adobe Photoshop 2026/27.8, the installed ground truth; every rule is pinned by PS COM captures unless noted. Fixtures named `photoshop-*` live in `test-fixtures/psd/`; `local-test-fixtures/` is machine-local. The COM workflow lives in [ps-compat.md](ps-compat.md).

## Per-effect calibration notes

- **Layer Style dialog**: footer `Preview` is transient and always opens enabled (off restores the original canvas while edits accumulate; Accept returns the edits regardless). `Show Effects` is the persisted `masterFXSwitch` (`LayerStyle::effects_visible`).
- **Blend If rendering**: the four active Gray/R/G/B gates multiply, and This Layer multiplies Underlying Layer. A split black range `[a,b]` retains byte v as `(v-a+1)/(b-a+1)` for `a <= v < b`; joined `a=b` is a hard cutoff; the white side mirrors the inclusive feather, zero immediately above `white_high`. Composite Gray = integer weights `299R + 590G + 111B`, rounded at 1/1000. Underlying coverage = `(1-da) + da*gate` (transparency always passes). Effects do not inherit the base-pixel gate; adjustments evaluate This Layer on the adjusted output and Underlying on the pre-adjustment backdrop; a nondefault folder range evaluates its isolated group against the outside backdrop; Blend If on a clipping base does not shrink clipping coverage. Fixtures `photoshop-blend-if-4b-roundtrip.psd`/`-render.bmp` (within 2/255).
- **Satin rendering**: from the post-mask alpha matte A: offset `v = (round(max(1,d) cos a), round(-max(1,d) sin a))`, signed difference `A(x+v) - A(x-v)`, Size blur, absolute value. Size 0 skips blur; Size n uses the exact separable tent kernel `(N-|k|)/N^2`, `N = max(2, n)`. Invert applies `1-q` after the Linear contour. The Satin color/mode folds into the layer's straight RGB before compositing, so alpha, masks, opacity, and backdrop apply once.
- **Stroke layer effect**: an exact-Euclidean **distance band** from the binary contour ({alpha > 0}), not a dilation; coverage formula in `stroke_alpha_mask` (src/render/layer_compositor.hpp), contour 0.5 px past the last pixel center, 1 px AA ramp, sum combine (not max) so the band stays seamless over AA contour pixels. Bands: Outside = size out, Inside = size in, **Center = size/2 each way**. Runs match PS run-for-run at every position, sizes 5-20 (`photoshop-stroke-positions.psd`). EDT: `exact_squared_distance_transform` (Felzenszwalb-Huttenlocher, deterministic). **Layer mask**: by default the mask reshapes the contour like pixel transparency where fully black (shape = {alpha > 0 AND mask > 0}) and the band lands on mask-hidden ground at FULL strength (`photoshop-stroke-masked.psd`); with 'lmgm' the contour ignores the mask and the OUTPUT is hidden instead (via Action Manager, 'lmgm' rides INSIDE the Lefx descriptor as `layerMaskAsGlobalMask`; a bare `setd` on the layer wipes the effects). Fractional mask values multiply into the content alpha the band is built from, so a feathered mask follows the semi-transparent rules below (psd-tools' feathered-stroke.psd: opaque pixels under a soft mask). **Strokes on semi-transparent content** (39 PS 2026 probes, October 2026: a red square whose alpha ramps 1 to 0, a flat 50% square and an AA circle, each with Outside/Inside/Center strokes at stroke opacity 50, layer opacity 50, Fill Opacity 50, Overprint on, and a Multiply stroke; local-test-fixtures/stroke-alpha-probes, `stroke_on_semi_transparent_content_matches_photoshop_probes_if_available`): every pixel with 0 < a < 1 is two disjoint paints. The OUTER band sits UNDER the content and takes the pixel's missing alpha, (1 - a) times the stroke opacity (times the gradient alpha); Fill Opacity scales the content share only, so a 50% square with Fill 50 reads 25% content, 50% stroke, 25% backdrop; layer opacity scales the pair; a Multiply stroke blends against the backdrop first. The INNER band treats every such pixel as band at coverage a and REPLACES the content (no content survives, even with Overprint on, even at stroke opacity 50: a flat 50% square with an Inside stroke is a uniform 50% stroke wash). A Center stroke is both, so that square turns into the full stroke color. The band's outermost ring reads the edge alpha (a 50% square has a 50% ring, the ramp's ring fades with it): the reach is `band + edge alpha - distance` from the pixel centers, the edge alpha approximated by the largest alpha within the band's reach (`dilate_mask`), and a semi-transparent contour pixel with no opaque neighbour inward (semi-transparent content, not an AA edge) anchors at 1 so that pixel-center geometry applies; AA edge pixels keep the subpixel half-coverage crossing (both decided per pixel, so a cropped render agrees with the full one). Renderer: `stroke_alpha_mask` fills `StyleMaskEntry::underlay`/`inside`/`knockout` beside the over-draw mask (which is zero on such pixels), the base pass folds both shares into the pixel (`underlay_strokes`, `prepared_stroke_underlay`), the knockout factor uses the band membership (`prepared_stroke_knockout_coverage`) and runs for these layers even for an opaque solid stroke, and a layer whose own blend cannot carry the fold (non-Normal mode with Fill Opacity or Blend If) draws the planes on top instead (`draw_includes_underlay`). Opaque mattes carry no planes and keep their pinned bytes. Residual: the band's outer corners (PS keeps them a little fuller) and the rare non-Normal fallback. The committed `photoshop-stroke-partial-alpha` fixture now pins Photoshop's sampled values (50% region = half content, half stroke). **Overprint band knockout** (distinct from the fill-alpha limitation, which stays divergent): with FrFX `overprint` OFF (PS default) the band knocks the layer's own content out at FULL band coverage regardless of stroke opacity, and the stroke blends against the layers below with its own mode; interior effects vanish under the band; clipped members are knocked out with their base; an opaque Multiply stroke multiplies the BACKDROP; at reduced opacity the band is `lerp(backdrop, blend(stroke, backdrop), opacity)`; layer opacity scales the whole plane. Overprint ON blends the stroke over the layer's own content. Renderer: per-pixel base-content factor (`StrokeKnockoutPlane`/`stroke_knockout_factor`, layer_compositor.hpp) applied by the base pass, interior effects, and satin/vector-restamp paths; Normal strokes use the compensated divisor `(1-C)/(1-s)` (exact; no-op for opaque solid strokes), non-Normal plain `(1-C)`. The knockout applies at **0% stroke opacity** too: gate only the draw on opacity, never the knockout. Fixture `photoshop-stroke-overprint.psd/bmp`.
- **Interior effects vs the VECTOR stroke** (fx-sofi-center/outside/nofill and fx-drsh-outside probes, July 2026): interior overlays (Color/Gradient/Pattern Overlay) apply to the FILL plane only and the vector stroke composites above them; on a stroke-only shape (fill disabled) the overlay covers the stroke itself; drop shadows (and the silhouette generally) key off the full fill+stroke coverage (coverage, not painted alpha: see "Effect silhouette of shape layers"); the Stroke EFFECT (frFX) stays above the vector stroke. Implementation: split fill/stroke planes (`ShapeRasterResult::fill_pixels`/`stroke_pixels`, empty when inapplicable); overlay passes read the fill plane and re-stamp the stroke (`compositor_interior_overlay_stays_under_vector_stroke`, src/render/layer_compositor.hpp). Blend-If layers and transform-preview overrides keep the legacy combined-plane behavior. Inner effects keep their full-silhouette geometry.
- **Effect silhouette of shape layers** (13 PS 2026 probes on one shape of psd-tools' `effects/stroke-effects.psd`, a square whose gradient fill fades to transparent, against its rasterized twin; October 2026): on a shape or fill layer every effect (Stroke at all three positions, Drop Shadow with and without `layerConceals`, Outer/Inner Glow, Inner Shadow, Bevel, Satin, the overlays) takes the shape's COVERAGE as the layer's silhouette, at full strength, wherever the gradient or pattern fill is transparent. A 100% Color Overlay turns the whole square opaque; the fill's transparency thins only the fill's own pixels. The rasterized twin follows pixel alpha. Keying effects off painted alpha drew triangular strokes around those squares. Implementation: `ShapeRasterResult::matte_pixels` / `VectorShapeContent::effect_matte_cache` holds the layer's RGBA with alpha replaced by fill and stroke coverage, only when a gradient or pattern fill makes the two differ (solid fills carry no plane and render byte-for-byte as before); the split `fill_cache` gets the fill's coverage as its alpha for the same reason. `composite_pixel_layer` hands that plane to every effect pass (`effect_matte_source_for_render`), and such layers skip the overlay and Satin folds (the fold rides the base alpha) for the destination passes. An imported shape that keeps Photoshop's raster gets the plane from `refresh_vector_shape_effect_matte` (psd_vector.cpp `finalize_vector_layers`); the vector preview renderer carries it too. Aligned overlay gradients on such a layer span the layer's bounds. Merged compound shapes (`parts`, Patchy-only) keep painted alpha. Pinned by `compositor_effects_follow_shape_coverage_under_transparent_fill`; `shape_effect_silhouette_matches_photoshop_probes_if_available` compares the probes (local-test-fixtures/shape-fx-probes, each file's composite is Photoshop's render) and agrees on every pixel except 8 corner pixels of the outside stroke and glow.
- **Drop shadow and outer glow share ONE soft-effect pipeline** (`prepare_photoshop_soft_effect_mask`, layer_style_mask_ops.cpp): (1) Spread expands the matte by the INTEGER radius `lround(spread% * size)` as a GRAYSCALE dilation (alpha x area-sampled disc; radii above 8 fall back to the binarizing chamfer band, which overshoots AA text ~20%); (2) the remaining size blurs with Satin's tent kernel, `N = max(2, lround(size)) - spread_radius` (NOT a triple-box). Spread 100 or size 0 = hard band with 1 px AA ramp; sizes 1-2 still blur with N=2. Never reimplement spread as a post-blur gain: saturating a blur's tail exposes the kernel support as per-glyph boxes.
- **Continuous (long) drop shadow** (Patchy-only, no PS counterpart; `LayerDropShadow::continuous/fade`): `sweep_layer_style_mask_in_place` (layer_style_mask_ops.cpp) extrudes the UNSHIFTED matte along the integer offset before the spread/size pipeline above runs, so Size and Spread soften the swept band and `layerConceals`, masks, opacity, and blend mode apply unchanged. The grid is partitioned into digital lines along the major axis (intercept `minor - floor((2 u step + L) / 2L)`, u counted in the sweep direction, L = max(|dx|, |dy|)); each line runs a monotone-deque trailing maximum over L + 1 samples, O(W x H). Fade multiplies the swept value by `1 - fade * t / L`, t = samples since the last matte value above zero (exact on hard mattes, approximate on AA edges). `render_drop_shadow` unites the source and shifted rects for the effect bounds and adds L to the mask apron so windowed renders match full ones, then bounds that apron by the window plus the source (the only matte the sweep can carry), so a 30000 px shadow stays canvas-sized; a zero offset takes the plain path bit-for-bit. Pinned by `compositor_continuous_drop_shadow_sweeps_to_offset_and_fades`.
- **Effect planes composite with burn-mode alpha FOLDED into the color**: LinearBurn and ColorBurn scale the effect color toward WHITE by its alpha and blend at full coverage (a 50% black linearBurn shadow subtracts an absolute `255 * mask * opacity`; the plain `lerp(b, blend(b, color), alpha)` model is refuted). **ColorDodge folds toward BLACK** (`color * alpha`). Normal, Multiply, Darken keep the plain model; source-affine modes are identical either way; other non-affine light modes are unprobed on the plain model. `composite_effect_color` (layer_compositor.hpp) folds every effect draw; layer PIXEL compositing keeps the standard model.
- **"Layer Knocks Out Drop Shadow" (DrSh `layerConceals`, default ON)**: the layer's transparency shape multiplies its own shadow by `(1 - matte)`, regardless of fill opacity (fill-0 shows no shadow inside), master opacity, or a Stroke Overprint knockout; OFF shows the shadow through proportionally. Invisible under opaque content. `LayerDropShadow::layer_conceals`; the pinned 12-item DrSh shape already carried the key. Fixture `photoshop-shadow-conceals.psd/bmp`.
- **Interior effect stacking order**: bottom-to-top overlays (pattern, gradient, color), then satin, then inner glow, then inner shadow, so interior effects blend against the OVERLAY-APPLIED content. **Interior overlays fold into the layer's straight RGB inside the base pass** (`prepare_interior_overlays`/`fold_interior_overlays`, layer_compositor.hpp), like Satin, so alpha, mask, stroke knockout, Fill/layer Opacity, and backdrop apply once; a 100% Normal overlay therefore hides the layer's pixels outright (a per-overlay destination pass leaks `1 - opacity` of the layer color and over-composites semi-transparent interiors), and Satin sits ABOVE the overlays. Three cases keep the legacy destination passes (the fold cannot express them) and still show the layer-opacity leak: Blend If (PS does not gate effects with it), Fill Opacity (scales pixels but not effects), and the shape-layer fill/stroke split (folding would tint the stroke); closing them needs the per-layer compositing buffer.
- **A clipping base's effects render over its clipped members** (`ClipRunContent`, layer_compositor.hpp; rules and fixture in [ps-compat.md](ps-compat.md) "Clipping masks"): the base pass reads its color from the merged base-plus-members buffer while every effect mask keeps the real source. The clip fixture's inner shadow uses size 1 with choke 100%.
- **Size 0** (`photoshop-size-zero-effects.psd/bmp`, September 2026): Inner Shadow draws the inverse matte offset by the rounded distance vector as a hard band, choke irrelevant (7 px at distance 10 / angle 135, 5 px at angle 90, nothing at distance 0); Inner Glow Edge renders nothing while Center fills the whole shape (the complement of the empty edge field); Drop Shadow is a hard offset band; Outer Glow renders nothing even at spread 100. `render_inner_shadow` and the Center-source `render_inner_glow` therefore no longer return early at size 0; the interior soft mask already degenerates to the unblurred inverse matte there.
- **Interior soft-mask falloff** (Precise-only; the earlier choke-only calibration kept a historical box blur at choke 0): `prepare_photoshop_interior_soft_mask` (layer_style_mask_ops.cpp) is the exact interior mirror of the exterior pipeline: the INVERSE matte dilates by `lround(choke% * size)` (`dilate_layer_style_mask_by_radius`: exact disc through radius 8, chamfer above), then tent-blurs with `N = max(2, lround(size)) - choke_radius` (choke 100 or size 0 = hard band). Byte-matched, thin-bar overlaps and dot corners included. Unpinned: an exactly-half shadow offset (cos60 x 5 = 2.5) rounds DOWN in PS where lround rounds up; fixtures use angle 90.
- **Inner glow Technique/Range** (`photoshop-inner-glow{,-range}.psd/bmp`, `photoshop-inner-shadow.psd/bmp`): Edge source = interior falloff, then the Range gain `min(1, blur * 100/Inpr)` applied AFTER the blur. **Center source = the exact complement of the gained Edge field**, `1 - min(1, edge * gain)`. A descriptor omitting `Inpr` renders at Range 100 in BOTH glows (never fall back to 50; legacy Patchy files always wrote an explicit 50). The regenerated IrGl is PS's 12-item shape with `GlwT` between `Opct` and `Ckmt` plus stored `Inpr` (`LayerInnerGlow::technique/range`). Technique "Precise" keeps the historical triple-box falloff verbatim (approximate; Range not applied). Residuals: choke radii above 8 chamfer; two-edge overlaps differ ~1/255 (PS byte-rounds between tent passes).
- **Outer glow "Softer"** (`photoshop-outer-glow{,-range}.psd/bmp`): spread dilation, tent blur `N = max(2, lround(size)) - spread_radius`, then the Range gain `min(1, blur * 100/Inpr)`. **Range's UI default is 50, so real files render TWICE the raw blur**; an Action-Manager-authored glow omitting `Inpr` gets 100, which is why naive probes miss it. `prepare_outer_glow_softer_mask`; `GlwT`/`Inpr` parsed, modeled (`LayerOuterGlow::technique/range`), and written (PS round-trips them). "Precise" keeps the legacy distance-ramp render (approximate; Range not applied). Residuals: spread radii above 8 chamfer; spread-100 corner arcs differ ~1 px.


Styled groups derive effects from their full child silhouette, including children
outside the canvas. The silhouette and isolation buffers span the children's
render bounds only (`group_content_bounds_for_render`), never the group's own
effect padding: effects paint straight into the destination, and Photoshop's
30000 px shadow Distance would otherwise allocate that padding. Inner shadows
clamp each offset axis to the layer extent plus size + 2, past which every
interior sample is already outside the layer. The UI caches that silhouette with the style masks and keys
group entries on descendant render revisions. Strips and dirty rectangles share
the same source. Burn/Dodge effect opacity grows transparent coverage by the real
effect alpha while retaining the folded blend against existing content. Large
stroke mattes use native-resolution distance fields above the supersampling budget
in `layer_style_mask_ops.cpp`; this bounds the extra allocation at the cost of
subpixel contour precision for those large mattes.
